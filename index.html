Know the limits
UTF-8 and BOM-marked UTF-16 input; 100,000 records, 200 columns, 500,000 cells. Invalid files are rejected. Preview is only the first ten records. CSV cannot force Excel to keep IDs as text: use Text/CSV import and select Text for those columns. Formula-like values are flagged but unchanged. No security guarantee, XLSX or merged output.
